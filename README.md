
# Apprehending Enchantment (NeoForge 1.21)

- Endless Suffering (I–IV): Applies to any chest armor tagged `#minecraft:enchantable/chest_armor`. Removes durability regeneration; repairs require Mending or manual methods. Anvil-only; cannot appear in enchantment table.
- Apprehending (I–III): Killing mobs with an enchanted sword or axe has a chance to drop that mob's vanilla spawn egg. Player-only kills; excludes bosses; not affected by Looting. Applies to any item tagged `#minecraft:axes` or `#minecraft:enchantable/sharp_weapon`.

## Installation
- Requires Minecraft `1.21.x` and NeoForge.
- Place the mod JAR in `mods/`.

## Obtaining
- Endless Suffering: Apply via anvil to any chestplate that participates in `#minecraft:enchantable/chest_armor` (vanilla and modded items).
- Apprehending: Apply via table or anvil to any sword or axe participating in `#minecraft:axes` or `#minecraft:enchantable/sharp_weapon`.

## Compatibility
- Uses vanilla enchantability tags for broad cross-mod coverage.
- Modded items that add themselves to these vanilla tags will automatically be eligible.
