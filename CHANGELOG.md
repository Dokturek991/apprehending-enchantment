# Changelog

## 0.2.0 — Tag-based compatibility release
- Endless Suffering: `supported_items` updated to `#minecraft:enchantable/chest_armor` for full cross-mod chestplate coverage; remains anvil-only.
- Apprehending: `supported_items` and `primary_items` now include `#minecraft:axes` and `#minecraft:enchantable/sharp_weapon` (covers swords and axes from mods).
- README reorganized to clearly describe features, obtaining, and compatibility.
- Version bumped to `0.2.0` in `gradle.properties`.

## 0.1.3 — Initial public release
- Base features implemented for Apprehending and Endless Suffering.
